# Dashboard estilo TradingView en Tailwind CSS v4

Proyecto de dashboard responsive con estética tipo TradingView para una influencer que necesita medir comisiones, conversiones, engagement, rendimiento por plataforma y rendimiento por producto.

## Tecnologías

- HTML
- Tailwind CSS v4 mediante `https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4`
- CSS mínimo de apoyo visual en `styles.css`

No usa React, Vue, JavaScript propio ni `cdn.tailwindcss.com`.

## Estructura

- Bloque superior: KPIs principales.
- Bloque intermedio: drivers de resultado.
- Bloque inferior: tablas, alertas y oportunidades.
